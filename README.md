# 📁 Organizador Automático de Downloads

Uma ferramenta simples e eficiente em Python para acabar com a bagunça da sua pasta de Downloads. O script detecta automaticamente a extensão dos archivos (como `.pdf`, `.png`, `.zip`) e os move para pastas categorizadas de forma organizada e rápida.

---

## 🚀 Funcionalidades

- **Detecção Automática:** Identifica o caminho correto da pasta Downloads no Windows, Mac ou Linux.
- **Categorização Inteligente:** Cria e separa arquivos em pastas específicas (Imagens, Documentos, Mídias, Compactados, etc.).
- **Seguro:** Ignora pastas já existentes para evitar alterações indesejadas no seu sistema.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- Biblioteca `pathlib` (Manipulação de caminhos de arquivos)
- Biblioteca `shutil` (Movimentação e utilitários de arquivos)

---

## 💻 Como Executar o Projeto

### Pré-requisitos
Você precisa ter o **Python 3** instalado na sua máquina.

### Passo a Passo
1. Baixe o arquivo `organizador.py` ou clone este repositório:
   ```bash
   git clone https://github.com
   ```

2. Abra o terminal ou prompt de comando na pasta do projeto.

3. Execute o script:
   ```bash
   python organizador.py
   ```

Pronto! Sua pasta de Downloads já estará limpa e organizada.
